# Welcome to nodal-lines!
In this repository you can find the corresponding Python code to the paper **''Investigating parameter dependence for counterexamples to Payne’s nodal line conjecture using HPC``** by Sina Mattfeldt and Andreas Kleefeld. The preprint is uploaded to arXiv [arXiv:2611.12542].

The core functions to calculate a nonlinear eigenvalue problem with the Beyn algorithm and solving the Helmholtz equation with the boundary element collocation method with MPI4py is located in src/DoubleLayerWithHoles.py.

The results for the paper are generated in the notebooks, which are seperated into the different chapters of the paper. The plots can be found additionally in the folder results.
